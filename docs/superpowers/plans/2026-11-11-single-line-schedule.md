# 单行课表与字体微调

用户已明确选择每节课所有字段在一行，接受较小字号。保持现有湖面羽毛背景及标题，仅调整课程信息布局。

- 新旧项目均使用五列：星期、起止时间、完整课名、教师、教室。取消时间及教师/教室的上下排列。
- Design 增加可选 scheduleStyle：mode(auto/manual)、fontSize(16–32)、courseWidth(40–54 百分比)、rowGap(12–44)。旧数据缺少该项时使用自动、28px、46%、24px，不修改任何课程数据。
- 纯函数使用真实字体测量完整字段，自动模式选整张表统一字号，最低18px。手动模式保留用户字号。宽度或高度仍不足时阻止导出并明确提示，禁止裁切、缩略或重新换行。
- 预览及PNG继续同一画布；列间留白，行高一致，星期按组显示。
- 编辑面板「版式与风格」提供自动适配、字号、课程栏宽度、行间距、一键恢复自动；设置随当前项目保存。
- 验证长中文含括号、所有列同一y坐标、三个图片尺寸、手动设置与刷新恢复、旧项目和旧备份兼容、超长字段保护、移动端。通过后发布到现有GitHub Pages网址。
