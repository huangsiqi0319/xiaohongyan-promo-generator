# 小鸿雁宣传物料生成器 · 第一期

用户提供的完整需求是本期实施依据，优先完成可实际使用的课程表和价目表。面向没有设计经验的舞蹈机构工作人员；无账号、数据库、付费 API 或生图服务。

## 实现选择

仓库只有 README。采用 React、TypeScript、Vite，静态部署兼容 Vercel。相比 Next.js，此项目无服务端需求；相比 DOM 截图，Canvas 统一绘制可让预览和 PNG 使用同一像素来源，避免字体和布局差异。此为实施选择。

## 设计

雾白工作台、低饱和灰蓝主按钮、粉灰辅助色、暖灰褐文字。中文标题使用本地开源 Noto Serif SC，正文 Noto Sans SC。左侧模板和编辑表单，右侧画布及尺寸控制；手机上下排列。画面使用细线、留白、轻透信息层，不使用人物、红金、促销标签。

每种模板有雅序、留白两种布局。课程按星期、时间稳定排序；价目自由排序；活动基础版包含全部文字、可选照片和二维码。所有初始内容明确标注为演示。

## 数据与素材

localStorage 保存多项目、当前项目和上次内容；IndexedDB 保存上传图片，避免 localStorage 大图容量限制。自动保存有真实失败状态；支持复制、重命名、删除、恢复前次编辑及 JSON 备份。六张原图尚未出现在可读文件系统中，不得虚构已接入。支持批量导入并保留原图，不生成替代背景。课程表与价目表只使用经用户确认为无人像的素材；活动照片与二维码独立于背景。

## 绘制与导出

画布宽 1080，高 1920 / 1440 / 1080。等待本地字体和图片解码后绘制。measureText 测量中文、拉丁长词、显式换行；课程和价格逐项计算高度，正文设最低字号。内容超出安全区时给出明确提示并禁止导出，建议更长尺寸或另一布局，不静默裁切。PNG 直接来自预览画布，不含编辑界面。

## 验收

单元测试验证星期时间排序、项目操作、存储损坏恢复和排版换行。浏览器验证三类模板编辑、添加删除排序、多项目和刷新恢复、实际图片导入及刷新、三尺寸 PNG 尺寸与画布一致、长文字溢出提示、移动端显示。运行 TypeScript 检查、单元测试、生产构建及 Chromium 端到端测试。
