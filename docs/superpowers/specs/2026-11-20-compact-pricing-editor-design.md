# 价目编辑区紧凑布局

用户已认可「显示／栏目名称／列宽」同排、价格内容集中表格、赠品备注折叠、固定查看成图入口的手机样稿，要求仅改变构图，保留当前网站的所有字体、颜色和边框风格。继续更新原网站。

## 范围

- 仅修改价目编辑区及手机快捷预览导航，不改模板绘制、素材、数据结构、旧数据迁移和收费内容。
- 栏目设置为紧凑网格，每列的显示复选框、名称输入、宽度数字与更多操作在同一行。排序和删除收进「…」，不删功能。
- 价格内容采用可直接输入的表格。显示开关及首个名称列固定；其余列在表格容器内部横向滚动，页面不横向溢出。隐藏的列仍能编辑并标注已隐藏。行排序/删除、逐行赠品备注通过「…」进入；以当前 ID 定位，避免排序后操作错误项目。
- 分区赠品/备注总开关、附注以及底部说明默认折叠，需要时展开；新添加说明可以自动展开。
- 手机底部使用现有 editor-bottom / primary-button 外观，固定「查看成图／返回编辑」按钮。跳到同一个实际预览画布，再返回原滚动位置；不复制画布、不重新生成图片、不更改成图和导出。
- 无论怎样折叠、预览、返回和重排，已输入内容仍自动保存，列的 ID 和单元格关联保持不变。

## 外观保留

保留现有字体、字号、文字颜色、背景、边框颜色/粗细、圆角与复选框颜色。新元素复用已有字段、按钮、折叠项和 UtilityDialog 的样式。布局 CSS 只调整排列、间距、宽度、滚动与定位。不会照搬 AI 样稿里的新配色或字体。

## 验收

修改前记录当前演示设计的原始 PNG 与关键控件 computed styles。修改后在同一浏览器和设计下逐项比较，PNG SHA-256 以及控件颜色/字体/边框保持相同。320/390/430px 验证设置四项同排、表格内横向滚动、页面无横向溢出；编辑单元格、宽度、显示、菜单排序删除、赠品备注、折叠刷新均可用；快捷预览到达真实画布、返回原位且值不丢失。运行现有全量回归，一次只读审查，发布后核对线上资源。
