# 可编辑分区价目表

用户已认可 2026-11-20 聊天中的分区表格结构，并要求继续使用原有图库。随后明确纠正视觉：不要绿色文字框或绿色表头，采用原图库粉色湖面、大片留白、低饱和暖灰字体，字号及字体系统贴近现有课程表。已授权直接更新网站；本轮不接入共享云服务。

## 功能

保留物料标题编辑、六张背景、上传、裁切、雾白遮罩、Logo、预览和高清 PNG。本次仅重做价目内容。列标题、所有单元格为自由文本，可增删、排序、隐藏列；行与分区也可增删、排序、隐藏。首列表头同时作为分区名称。每行可填写赠品、备注，各自有保留内容的显示开关；每区有赠品/行备注总开关以及独立注意事项。底部支持多个自由命名的说明块（入会费、体验费等），可开关、排序、增删。全局货币说明、日期、底部备注可开关，所有开关隐藏后不占图片空间。

新项目提供日元演示数据：常规课五行，一对一/一对二各两行，入会说明；默认 1080×1920，金额明确为演示。已有项目不替换价格、不添加虚构私教/收费；按原类别转换，保留单次、套餐、课时、有效期、优惠及备注。旧结构字段仍保留以兼容旧数据，新增可选 pricingTable；读取时纯函数生成兼容视图，第一次编辑才保存新结构。复制设计时所有表格 ID 独立；备份、恢复和续编链接支持新结构。

## 排版

继续由 Canvas 绘制真实中文，与预览逐像素一致。雾白/原图库背景均可，默认沿用粉雾湖面；表头无填色，仅暖灰字与细横线，取消每行表格线，增加分区与行间留白。与课表共用 POSTER_THEME 中的 Noto Serif SC 宋体标题（76px，方形62px）、Noto Sans SC 正文、#514b48 深暖灰、#777571 辅助暖灰及同一细线颜色。无绿色、人物、粗边框或卡片叠加。显示列按相对宽度自动分配整行空间；可手动调整相对宽度。长文字根据实际字体测量换行、行高自动增大；表头、赠品、说明均计入高度。字号在 30–22px 自动适配，过长/过多内容不能安全显示时明确提示切换尺寸/减少显示内容并禁用导出，禁止静默截断或覆盖。

## 验证与交付

验证旧项目和旧备份可读，新结构非法数据被拒绝；隐藏保留内容、复制独立、动态布局无重叠、长字和全隐藏不崩溃。浏览器实际编辑行列、分区、说明、刷新恢复、图库切换/遮罩、三尺寸与 Canvas 一致导出；桌面及 320/390px 手机检查。保留课程表、活动、手机图片保存和备份回归。审查后提交并通过现有 GitHub Pages 工作流更新原网址，发布后核对线上资源与测试构建一致。
