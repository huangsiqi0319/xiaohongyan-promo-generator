# 开源依赖与字体

应用使用开源软件；实际版本由 `package-lock.json` 固定。

| 依赖                                            | 用途       | 许可证                    |
| ----------------------------------------------- | ---------- | ------------------------- |
| React / React DOM                               | 前端界面   | MIT                       |
| Vite                                            | 开发与构建 | MIT                       |
| TypeScript                                      | 类型检查   | Apache-2.0                |
| Lucide React                                    | 界面图标   | ISC                       |
| Vitest                                          | 单元测试   | MIT                       |
| Playwright                                      | 浏览器验证 | Apache-2.0                |
| Noto Serif SC / Noto Sans SC（Fontsource 分发） | 中文字体   | SIL Open Font License 1.1 |

字体的完整许可证位于依赖包 `@fontsource/noto-serif-sc/LICENSE` 和 `@fontsource/noto-sans-sc/LICENSE`，并复制到 `public/licenses/` 随站点分发。字体可按 OFL 许可随站点分发并用于商业设计；未单独出售字体。生成的 PNG 无需额外购买字体软件。

用户上传的背景、Logo、照片和二维码由用户自行提供，本项目不生成替代艺术背景，也不声明拥有这些素材的版权。
