# 小鸿雁宣传物料生成器

**在线使用：[打开小鸿雁宣传物料生成器](https://huangsiqi0319.github.io/xiaohongyan-promo-generator/)**

无需下载或解压。项目已通过 GitHub Pages 发布；数据仍保存在各自浏览器中。初次打开的课程、教师及价格为演示数据，请替换后再用于正式发布。

面向舞蹈艺术机构的本地品牌物料工作台。选择模板、编辑内容、实时预览并导出高清 PNG；无需账号、数据库、付费 API 或 AI 生图。

## 本地开发

使用 Node.js 24：

```bash
npm ci
npm run dev
```

云环境若默认 npm 缓存目录不可写，改用 `npm ci --cache /workspace/.npm-cache`。使用现有检出目录 `/workspace/xiaohongyan-promo-generator`，无需新建 worktree。

```bash
npm test             # 业务与排版单元测试
npm run typecheck    # TypeScript 检查
npm run build        # 生产构建，输出 dist/
npm run test:e2e     # Chromium 真实浏览器测试
```

当前云环境使用 `/usr/bin/chromium`。其他机器请设置 `CHROMIUM_PATH` 为本机 Chromium 路径，或先运行 `npx playwright install chromium` （测试配置会自动使用下载的浏览器）。

## 已实现

- **课程表**：标题、日期范围、星期、起止时间、课程、教师、教室、备注，课程增删，按星期与时间自动排版。
- **价目表**：价格类别、名称、单次 / 套餐价格、课时、优惠说明、有效期及项目备注，增删与上下排序。
- **活动基础版**：标题、副标题、介绍、日期、时间、地点、价格、教师、报名方式，可选照片及已有二维码图片。
- **统一品牌样式**：低饱和雾白、粉灰、灰蓝、暖灰褐；本地开源中文宋体标题 / 无衬线正文；雅序与留白两种版式。
- **PNG 导出**：1080 × 1440、1080 × 1920、1080 × 1080。预览和下载来自同一 Canvas；等待字体与图片后才允许导出。
- **防溢出**：测量文字实际宽度和换行，高密度时不无限缩小字号；超出安全区提示调整尺寸、布局或内容，并阻止导出。
- **本地项目**：自动保存、多项目、复制、重命名、删除、恢复前次编辑；损坏内容不自动覆盖，保存失败不假报成功。
- **素材管理**：背景批量导入、原图保存、裁切和雾白遮罩、Logo、活动照片及二维码；图片使用 IndexedDB，文本使用 localStorage。
- **完整备份**：JSON 包含全部设计与原图，可导入其他浏览器；导入采用新 ID，保留当前项目。
- **响应式**：电脑左右工作区、手机上下布局。

## 原图接入与演示数据

**已接入用户提供的 xiaohongyan.zip：7 个 JPG 文件按原始字节去重后，保留 6 张不同的背景。所有原图未经重绘或重新压缩，随应用内置；新设计默认使用「云水羽梦」。**

在「品牌素材」中可以直接切换六张原图，也可以选择纯雾白底。原有设计的内容和背景选择保持不变；此前使用纯色的项目，点击任一原图即可套用。还可上传新的 JPG / PNG / WebP（每张不超过 20 MB）。调整「版式与风格」中的裁切位置与遮罩。原图备份在 public/backgrounds/，应用使用相同字节的内嵌图片，不依赖外部图床。

运行 `node scripts/package-standalone.mjs` 可将生产构建打包为含字体、程序和六张原图的单文件 HTML，输出在 artifacts/。下载后可在常规浏览器中打开；它不是已上线的公网网站。

课程表和价目表不会使用活动人物照片。背景需要上传者确认不含人物；应用没有接入图像内容识别服务。Logo 亦请使用机构的实际标识。

默认课程、教师、时间、价格均为**演示数据，不代表机构真实安排或收费**，图片中默认带演示标识。正式发布前替换数据，并自行关闭演示标识。

## 保存与恢复

编辑后立即保存至当前浏览器；前次恢复按连续输入分组，恢复按钮可在两次版本间切换。项目和图片在刷新、关闭再打开后保留。

数据不跨设备自动同步，清除网站数据、隐私模式或存储空间不足可能影响保存。请定期在「我的设计」下载完整备份；图片备份包含原图。备份导入是追加，不会替换已有设计。

## Vercel 部署

将此仓库导入 Vercel，选择 Vite：

- Install Command：`npm ci`
- Build Command：`npm run build`
- Output Directory：`dist`
- Node.js：24.x

不需要环境变量、密钥或后端。所有字体随站点托管，正常运行不依赖外部字体 CDN。尚未在真实 Vercel 账号中执行部署。

## 代码结构

```text
src/
  components/     编辑表单、素材库、预览组件
  hooks/          项目状态、自动保存、图片生命周期
  lib/
    model.ts      三类模板数据、复制、课程排序、数据校验
    storage.ts    版本化本地保存与恢复
    assets.ts     IndexedDB 原图存储
    backup.ts     全项目与图片备份迁移
    layout.ts     文字测量换行、可读字号选择
    render.ts     可复用 Canvas 模板与统一品牌绘制
  types.ts        物料、课程、价格及素材类型
tests/            浏览器端到端验证
```

后续新增模板：扩展 `TemplateKind` 与数据结构，在 `render.ts` 增加对应的测量 / 绘制函数，再接入表单。测量与绘制必须使用相同逻辑，确保导出完整。
